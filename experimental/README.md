# Experimental crates

このディレクトリは **将来の再設計・分解用の予約スロット** です。

- **現行の主実装ではない**: 現在の製品ビルド・テストの既定対象には含まれていません。
- **default-members からは外している**: 通常の `cargo build` / `cargo test` ではビルド・テストされません。必要なら `cargo build -p <name>` で個別に扱えます。
- **本番利用前提ではない**: プレースホルダまたは試験用の境界として置いてあり、いつ本実装に昇格するかは未定です。

現在の正式な実装ルートは `apps/`, `bins/`, `libs/`, `tools/` です。初見の方はまずそちらを参照してください。
